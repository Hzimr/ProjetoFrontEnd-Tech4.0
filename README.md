# 🛍️ Digital Store - Projeto Final Front-end

<p align="center">
  <em>Aplicação web desenvolvida em React como projeto final do curso de Front-end Geração Tech 4.0, baseada no layout do Figma e na documentação oficial do projeto Digital Store.</em>
</p>

---

## 🚀 Sobre o Projeto

Este repositório contém a implementação do e-commerce **Digital Store**. O objetivo principal foi aplicar tecnologias modernas e boas práticas de desenvolvimento front-end para construir uma experiência de usuário rica, responsiva e fiel ao design especificado.

### 🎯 Páginas Principais

- **Home (Página Inicial):** Vitrine principal com destaques, banners e produtos em evidência.
- **Listagem de Produtos:** Catálogo completo com opções de filtragem e ordenação.
- **Visualização do Produto:** Página de detalhes do produto contendo galeria de imagens, preço, descrições e opções de compra.

---

## 🛠️ Tecnologias Utilizadas

- **[React](https://react.dev/)** — Biblioteca principal para a construção da interface
- **[TypeScript](https://www.typescriptlang.org/)** — Tipagem estática para maior segurança e escalabilidade
- **[Tailwind CSS](https://tailwindcss.com/)** para estilização e design responsivo
- **[Vite](https://vite.dev/)** — Ferramenta de build e empacotamento rápido

---

## 📋 Pré-requisitos

Certifique-se de ter as seguintes ferramentas instaladas em sua máquina:

- [Node.js](https://nodejs.org/) (versão 18 ou superior recomendada)
- Gerenciador de pacotes `npm`, `yarn` ou `pnpm`

---

## ⚙️ Como Executar o Projeto Localmente

Siga os passos abaixo para rodar a aplicação em sua máquina:

```bash
# 1. Clone o repositório
git clone https://github.com/Hzimr/ProjetoFrontEnd-Tech4.0

# 2. Acesse a pasta do projeto
cd ProjetoFrontEnd-Tech4.0

# 3. Instale as dependências
npm install
# ou
yarn install

# 4. Inicie o servidor de desenvolvimento
npm run dev
# ou
yarn dev
```
